# 🧠 Employee Attrition Prediction ML Project

A machine learning model that predicts whether an employee is likely to leave the company.  
This project includes a **Streamlit web app** that allows HR professionals to input employee details and get **real-time predictions and insights** on employee retention.

---

## 📘 About the Project

Employee attrition is one of the major challenges organizations face in workforce management.  
This project uses **machine learning** to analyze employee data and predict the likelihood of attrition, helping HR departments take proactive measures.

The Streamlit app provides an easy-to-use interface where users can:
- Input employee data (e.g., age, job role, salary, satisfaction level)
- Get instant prediction results (Stay / Leave)
- Gain insights into factors affecting retention

---

## 🚀 Features

- Machine Learning model trained on HR dataset (`WA_Fn-UseC_-HR-Employee-Attrition.csv`)
- Streamlit web application for real-time predictions
- Preprocessing and feature engineering pipeline
- Pickled models (`.pkl`) for easy deployment
- User-friendly interface for HR professionals
